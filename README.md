# RailSathi (রেলসখা) - Indian Railways AI Travel Planner & Split-Ticket System

An advanced Indian Railways AI Travel Planner built with Redrail-like smart ticketing capabilities, operating strictly on Indian Standard Time (IST / Asia/Kolkata).

---

- 🇧🇩 **বাংলা (Bengali)**
- 🇮🇳 **हिन्दी (Hindi)**
- 🇬🇧 **English (English)**

---

## 🚀 Two Ways to Run & Deploy:

### 1. 📱 Android App (Jetpack Compose)
- **AI Studio:** Preview directly in the browser via Streaming Emulator.
- **Generate APK:** Go to Settings ➜ **Generate APK** to install directly on any Android smartphone.
- **GitHub Export:** Push directly to your GitHub repository from AI Studio settings.

### 2. ⚡ Vercel Deployment via GitHub (ওয়েব সংস্করণ)
This project includes a complete, high-performance React + Vite web version inside the `web/` directory with a root `vercel.json` configured for instant deployment.

#### How to deploy on Vercel:
1. Push this repository to **GitHub** from AI Studio.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"** ➜ **"Import Git Repository"**.
3. Select this repository.
4. **Deploy Settings:**
   - **Root Directory:** Either leave default (the included `vercel.json` handles it automatically) or set to `web`.
   - Click **Deploy**!
5. Your live web link will be ready in under 1 minute!
